# MOVIEFLIX / FREEDOM — เซิร์ฟเวอร์หลังบ้าน

เซิร์ฟเวอร์ที่ทำหน้าที่ **ล็อกอินจริง ตรวจสิทธิ์จริง และจัดการหนัง** ให้หน้าตาหลังบ้านเดิมเรียกใช้
(Node.js 20+ / Express / PostgreSQL 15+)

## สถานะงาน (พูดตรงๆ)

**ทำเสร็จและทดสอบแล้ว** (ทดสอบ 94 ข้อบนฐานข้อมูล PostgreSQL จริง: `npm test`)

| ส่วน | มีอะไร |
|---|---|
| ล็อกอิน | รหัสผ่าน scrypt, เซสชัน cookie HttpOnly, CSRF, ล็อกบัญชีเมื่อใส่ผิด 5 ครั้ง, จำกัดต่อ IP, ยืนยัน 2 ชั้น (TOTP) กันใช้รหัสซ้ำ, เปลี่ยนรหัส/ออกจากระบบทุกเครื่อง |
| สิทธิ์ | เจ้าของ / ผู้ช่วย / ดูอย่างเดียว ตรวจที่ฝั่งเซิร์ฟเวอร์ทุกคำสั่ง |
| หนัง | เพิ่ม แก้ ค้นหา กรอง ถังขยะ กู้คืน ลบถาวร ลิงก์ดูหนัง |
| เผยแพร่ | ต้องมีเจ้าของยืนยันสิทธิ์ก่อน (เซิร์ฟเวอร์ + ฐานข้อมูลกันซ้ำสองชั้น) |
| หมวดหมู่ / ประเภท | เพิ่ม แก้ ลบ (ลบไม่ได้ถ้ายังมีหนังใช้) |
| ผู้ดูแลระบบ | สร้างผู้ช่วย ระงับ เตะออกจากระบบ |
| บันทึกการใช้งาน | ใครทำอะไร ค่าก่อน/หลังแก้ |
| SeriesJeen V1+V2 | ผ่านเซิร์ฟเวอร์ คีย์ไม่ออกไปที่เบราว์เซอร์ นำเข้าเป็นฉบับร่างเสมอ |

**ยังไม่ได้ทำ (ตารางในฐานข้อมูลมีแล้ว แต่ยังไม่มีเส้น API)**
ตั้งค่าเว็บ, เมนูหัว/ท้าย, FAQ, บทความ SEO, แบนเนอร์, โฆษณา/VDO โฆษณา, ถ่ายทอดสด, แจ้งเตือน Push,
บัญชีรับเงิน/ตรวจสลิป, สมาชิกคนดู (สมัคร/ล็อกอิน), อัปโหลดรูปโปสเตอร์, หน้าเว็บฝั่งคนดู

## ติดตั้ง (งานของเดฟ ประมาณครึ่งวัน)

```bash
# 1) สร้างฐานข้อมูล แล้วรัน SQL ตามลำดับเลขหน้าชื่อไฟล์
createdb movieflix
for f in sql/0*.sql; do psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f "$f"; done

# 2) ตั้งค่า
cp .env.example .env        # แล้วกรอกค่า (สร้างกุญแจด้วย: openssl rand -hex 32)

# 3) ติดตั้งและสร้าง
npm ci && npm run build

# 4) สร้างบัญชีเจ้าของคนแรก (รหัสผ่านอย่างน้อย 12 ตัว)
OWNER_EMAIL=you@example.com OWNER_NAME="ชื่อคุณ" OWNER_PASSWORD='...' npm run create-owner

# 5) รัน
npm start
```

ข้อบังคับก่อนเปิดใช้จริง
- ต้องเป็น **HTTPS** เท่านั้น (ตั้ง `NODE_ENV=production` แล้ว cookie จะบังคับ Secure)
- ให้หน้าตากับ API อยู่ **โดเมนเดียวกัน** (เช่น nginx ส่ง `/auth`, `/admin`, `/api` ไปที่เซิร์ฟเวอร์นี้) เพราะ cookie เป็น SameSite=Strict
- ตั้งสำรองฐานข้อมูลอัตโนมัติและ **ลองกู้คืนจริง 1 ครั้ง**
- เจ้าของล็อกอินแล้วเปิด **ยืนยัน 2 ชั้น** ทันที
- ถ้าเคยกรอกคีย์ SeriesJeen ในหลังบ้านตัวเดิมที่เปิดบนเว็บ ให้ **ออกคีย์ใหม่** แล้วยกเลิกตัวเก่า

## ต่อหน้าตาเดิม

โฟลเดอร์ `frontend/` มี 2 ไฟล์

1. `adminApi.ts` → วางที่ `src/services/adminApi.ts` (ตัวเรียก API ทั้งหมด ไม่มีรหัสผ่าน/คีย์ ไม่ใช้ localStorage)
2. `LoginView.tsx` → แทนที่ `src/components/LoginView.tsx` (เลิกใช้ `INITIAL_USERS` และรหัส Admin123/Staff456 ที่ฝังในโค้ด, รองรับกรอกรหัส 2FA)

แล้วแก้จุดอื่นในหน้าตา (ผมยังไม่เห็น `App.tsx`, `types`, `services` จึงระบุเป็นรายการให้เดฟ)

| จุดในหน้าตาเดิม | ต้องเปลี่ยนเป็น |
|---|---|
| เปิดแอป/รีเฟรช | เรียก `auth.restoreSession()` ถ้าได้ `null` ให้แสดงหน้าล็อกอิน และเรียก `setOnUnauthenticated(...)` ให้พากลับหน้าล็อกอินเมื่อเซสชันหมดอายุ |
| ออกจากระบบ | `auth.logout()` |
| รายการหนัง (state ในหน้าตา / ข้อมูลตัวอย่าง) | `movies.list({ q, status, sort, page })` |
| ฟอร์มเพิ่ม/แก้หนัง | `movies.create` / `movies.update` และเพิ่มช่องติ๊ก "ยืนยันว่ามีสิทธิ์เผยแพร่" ส่งเป็น `rightsConfirmed: true` |
| ปุ่มลบ (`DeleteConfirmModal`) | `movies.trash(id)` เพิ่มหน้าถังขยะที่เรียก `movies.list({ trash: true })`, `movies.restore`, `movies.purge` |
| หมวดหมู่ (`CategoriesManagement`) | `categories.*` และ `genres.*` |
| ผู้ใช้งาน | `staff.*` (ลบรหัสผ่านออกจากชนิดข้อมูล User ในหน้าตา) |
| `ApiSyncModal`, `SettingsManagement` | เลิกยิง `api.seriesjeen.online` ตรงๆ และเลิกให้กรอกคีย์ในหน้าเว็บ ใช้ `seriesJeen.*` |
| ที่ใดก็ตามที่มี `localStorage` เก็บคีย์/รหัส/ผู้ใช้ | ลบออก |
| ซ่อนเมนูตามสิทธิ์ | `can(user, 'content.publish')` (แค่ความสะดวก เซิร์ฟเวอร์ตรวจสิทธิ์จริงอยู่แล้ว) |

ชื่อสถานะหนังเข้ากับหน้าตาเดิม: `active` = เผยแพร่, `draft` = ฉบับร่าง

## ข้อจำกัดที่ต้องรู้
- ตัวจำกัดความถี่ (ล็อกอินใช้ฐานข้อมูล / เส้นเล่นหนังใช้หน่วยความจำ) เหมาะกับเซิร์ฟเวอร์เครื่องเดียว ถ้าขยายหลายเครื่องต้องย้ายไป Redis
- แคชลิงก์เล่นของ SeriesJeen อยู่ในหน่วยความจำ ไม่เขียนลงฐานข้อมูล (ลิงก์หมดอายุราว 6 ชั่วโมงตามเงื่อนไขผู้ให้บริการ)
- ผมทดสอบกับ SeriesJeen จำลอง ยังไม่เคยยิง API จริง ต้องทดสอบด้วยคีย์จริงก่อนใช้งาน
- สิทธิ์เผยแพร่เชิงพาณิชย์ของ SeriesJeen: ต้องอ่านเงื่อนไขของเขาแล้วตั้งค่า `data_sources.license_status` เอง
